* Data Cleaning
* Data Privacy and Ethics
* Basic Data Analysis Techniques

### Key Learning Outcomes

* Navigate and work with Excel spreadsheets and workbooks.
* Enter, edit, copy, fill, and format data.
* Use formulas and common Excel functions for data analysis.
* Import and clean data in Excel.
* Identify and address duplicate, inaccurate, empty, and inconsistent data.
* Use sorting and filtering to analyze datasets.
* Apply lookup functions such as **VLOOKUP** and **HLOOKUP**.
* Create and work with **PivotTables**.
* Understand data quality, data integrity, and data privacy concepts.
